# Near Field / 近场

- Open [`index.html`](index.html) in a browser. No installation required.
- Aim to choose direction and activation distance. X marks where a shot is expected to become damaging. Move sideways to steer your bright shots.
- Left hand: move with the controller's left stick or WASD. Right hand: aim and fire with the mouse. Dual-stick and touch also work.
- Space pauses; R restarts. Design: czrorz. Code: ChatGPT.
