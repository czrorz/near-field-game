玩法说明
你对手暗弹无伤害亮弹能造成伤害

WASD 移动，鼠标瞄准。点击发射一组子弹，按住连续射击。P 键暂停或继续，R 键重新开始。结算后按空格键再来一局。

子弹出膛时是暗弹，飞到瞄准的距离才会变亮。只有亮弹能伤到对手。双方的暗弹相撞时有概率互相抵消。

最小瞄准圈朝移动方向偏移，圈边标出变亮所需的最短距离。距离线的两端对应子弹预计变亮和消失的位置。

每个角色身边有两种力场，都只影响亮弹。接收场让敌方亮弹减速、偏转，控弹场改变己方亮弹的方向。相对弹道横移时，力场会把子弹往你移动的一侧带。开火时相对射击方向横移会给子弹加上自旋，影响它在对手接收场里的弹道。

默认情况下，人物的生命值越低，体型越小，惯性也越低。

「默认」方案使用固定参数。1–4 号方案的修改会自动保存。

实验功能

按 Q 或 LT / L2，让己方亮弹朝对手收拢。

按鼠标右键，把己方亮弹翻到对手对侧，速度同时掉头。

按 Shift 或左肩键（LB / L1），沿移动方向闪避，起手减伤。

按 E，让己方亮弹原地停 1 秒。每颗弹只能停一次，停住时仍能命中，寿命暂停计时。

人物与移动

移动手感

数值越大，加速、减速和转向越慢。人物因生命值下降而缩小时，移动惯性也会降低。

人物属性

调整上限时，双方剩余生命值的百分比保持不变。

以满血时的半径为基准。设为 100% 时，人物大小不随生命值变化。

调整身体前后长度与左右宽度的比例，面积保持不变。

人物间排斥

两个人物的中心距离小于此值时，会互相推开。

靠得越近，排斥越强。设为 0 可关闭排斥。

视角与瞄准

仅用于随瞄准转动的视角。数值越大，看得越远。

关闭后，斜俯视沿用普通跟随俯视的平面瞄准换算。

瞄准灵敏度

灵敏度低于 100% 时会锁定鼠标。

辅助显示

射击

连发与装填

整组射击时，松手也会打完整组。

一组连发中每秒发射的子弹数。

每组最后一发打完后，需等待这段时间才能再次开火。调整弹匣容量、射速或装填时间，从下一组起生效。

手柄用左摇杆移动、右摇杆瞄准，按 RB 或 RT 射击。触屏在游戏区左侧 30% 按下出现移动摇杆，右侧 70% 拖动瞄准，默认自动开火。

子弹与弹道

飞行与碰撞

无阻力和外力时，每秒增加的弹速。

亮弹的伤害与飞行距离

从变亮时开始计时。飞完杀伤路程或达到时间上限时消失。暗弹最多飞行 4 秒。

不随瞄准距离变化的杀伤路程。

总杀伤路程 = 基础杀伤路程 + 附加杀伤路程 × 瞄准距离 ÷ 500。

子弹刚变亮时的爆炸伤害。

子弹变亮后，爆炸伤害在这段路程内从最低值均匀增加到 1000。设为 0 时，变亮就达到 1000。

发射自旋

自旋方向

勾选时，发射自旋的方向与横移方向相反。只影响之后发射的子弹。

数值越大，发射时产生的自旋越强。设为 0 时，发射的子弹不带自旋。

接收场

子弹越快，阻力越大。顺着来弹方向移动会减小阻力，迎着来弹移动时仍按弹速计算。设为 0 可关闭阻力。

人物沿垂直于弹道的方向移动时，力场会把子弹往同一侧带。设为 0 可关闭这个效果。

数值越大，子弹因自旋产生的偏转越明显。设为 0 可关闭这种偏转。

控弹场

控弹场影响己方亮弹的范围，用虚线圈标出。

人物沿垂直于弹道的方向移动时，力场会把子弹往同一侧带。设为 0 可关闭这个效果。

命中与击退

动量伤害

子弹相对目标撞得越快，动量伤害越高，擦中时伤害较低。设为 0 可关闭动量伤害。

设为 0 时，命中只造成爆炸伤害。

伤害越高、目标越小，击退越强。
